# P14: Is the Even AI Agent setting shown to every user?

## The question

The Even app has an Agent configuration under Settings, then Even AI. Does every user see it, or only users who are Even Hub developers?

## Why it matters

Apps that connect to Even AI through an agent need to tell users where to set it up. If only developers see the setting, those instructions fail for everyone else.

## Steps

This probe needs no code.

1. Use an Even account that has never signed in at the Even Hub developer portal (hub.evenrealities.com).
2. Sign in to the Even app with that account, with glasses paired.
3. Go to Settings, then Even AI.
4. Look for the Agent configuration.

## What to record

- Whether the Agent configuration shows.
- A screenshot of the Even AI settings page.
- Phone model, OS version, Even app version, glasses firmware.
- Confirm that the account never signed in at the developer portal.

## What we know so far

- One unsourced report (2026-10-06) says only developers see the setting. No page from Even confirms it.
- Not tested on an account.
